# Algorithm 6: Spatial Analysis Execution and Validation

Executes LLM-generated Python code in an isolated subprocess, collects
statistical results, and validates the output for common failure modes
(NaN values, missing summary files).

Reference: `modules/llm.py:_handle_spatial_analysis()`,
`modules/helper.py:run_python_code()`

```
Algorithm 6: Spatial Analysis Execution and Validation
----------------------------------------------------------------------
Input : code (Python script generated by LLM),
        analysis_type in {autocorrelation, colocation, correlation,
                          ripley_k, hotspot, spatial_distance},
        t_start (timestamp before tool invocation)
Output: (result_text, ToolCallRecord)

  // --- Preparation ---
 1  code <- StripMarkdownFences(code)
 2  code <- RemoveProseBeforeFirstImport(code)

  // --- Isolated Execution ---
 3  script_path <- WriteTempFile(code, encoding=UTF-8)
 4  env <- CopyEnvironment()
 5  env["PYTHONIOENCODING"] <- "utf-8"
 6  env["PYTHONWARNINGS"]   <- "ignore libpysal, ignore esda"

 7  (stdout, stderr) <- SubprocessRun(
        python, script_path,
        timeout=900s,
        env=env)

  // --- Error Detection ---
 8  has_error <- false
 9  if stderr contains any of {"Traceback", "Error", "Exception"} then
10      has_error <- true
11  end if

  // --- Collect Output Files ---
12  result_dir <- "results/visualisierung/" + analysis_type
13  geojson    <- FindLatestFile(result_dir, "*.geojson")
14  summary    <- FindLatestJSON(result_dir, written_after=t_start)

  // --- Statistical Validation ---
15  if summary is not null then
16      for each (key, value) in FlattenDict(summary) do
17          if key in {"moran_i", "i"} and IsNaN(value) then
18              has_error <- true
19              Append(warnings, "Moran's I is NaN: constant variable")
20          end if
21          if key in {"p_value", "p_sim"} and IsNaN(value) then
22              has_error <- true
23              Append(warnings, "p-value is NaN")
24          end if
25      end for
26  end if

  // --- Assemble Response ---
27  parts <- []
28  if stdout is not empty then Append(parts, stdout)
29  if has_error and stderr then Append(parts, stderr)
30  if warnings then Append(parts, warnings)
31  if summary then Append(parts, FormatJSON(summary))
32  text <- Join(parts, separator="\n\n")

33  return (text, ToolCallRecord(
        tool="run_spatial_analysis",
        success=not has_error,
        python_code=code,
        stdout, stderr,
        geojson_path=geojson,
        summary_json=summary))
```

## Subprocess Isolation Properties

| Property | Value | Rationale |
|----------|-------|-----------|
| Timeout | 900 s (15 min) | PySAL analyses on large grids can be slow |
| Encoding | UTF-8 forced | Windows default cp1252 fails on Unicode place names |
| Warning suppression | libpysal, esda | Disconnected-components and divide-by-zero warnings expected |
| Working directory | Temp directory | Script file deleted after execution |

## Expected Output Files

| File | Format | Content |
|------|--------|---------|
| `*.geojson` | GeoJSON FeatureCollection | Spatial units with analysis attributes (LISA clusters, Gi* z-scores) |
| `*.json` | JSON object | Summary statistics: Moran's I, p-value, n, analysis metadata |
